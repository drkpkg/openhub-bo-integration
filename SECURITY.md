# Seguridad

Estas librerías manejan credenciales de OpenHub, montos y webhooks de pago. Si encuentras una
vulnerabilidad, **no abras un issue público**.

## Cómo reportar

Usa el reporte privado de GitHub: pestaña *Security* → *Report a vulnerability*
(<https://github.com/drkpkg/openhub-bo-integration/security/advisories/new>).

Incluye la versión y el lenguaje afectados, los pasos para reproducirlo y su impacto. Responderemos
en un plazo de 7 días y coordinaremos contigo la publicación del arreglo y del aviso.

## Versiones con soporte

Mientras el proyecto esté en 0.x, solo la última versión publicada recibe arreglos de seguridad.

## Fuera de alcance

Vulnerabilidades de las APIs de Red Enlace (ATC) OpenHub: repórtalas directamente a ATC. Este
proyecto no está afiliado a Red Enlace.
