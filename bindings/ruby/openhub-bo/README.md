# openhub-bo

Metagema con todos los clientes Ruby para las APIs de **Red Enlace (ATC) OpenHub**, Bolivia.
Ruby no tiene "extras": si solo necesitas un producto, instala solo su gema.

| Gema | Require | Producto |
|---|---|---|
| `openhub-bo-core` | `openhub_bo/core` | Sesión, transporte, errores (va con todas) |
| `openhub-bo-qr` | `openhub_bo/qr` | QR Simple / QR MLD-BCB |
| `openhub-bo-fx` | `openhub_bo/fx` | PIX, USDT/USDC (Koibanx), Binance Pay |
| `openhub-bo-accounts` | `openhub_bo/accounts` | Cuentas, saldos, conciliación |
| `openhub-bo-payouts` | `openhub_bo/payouts` | Pagar QR de terceros, lotes ACH |
